Travailler avec Paul
Le Code

Cinq lignes.
Aucune négociable.

Les règles que Paul Dena s'impose dans chaque camp, chaque vlog, chaque interview. Pas un slogan marketing — un cadre de travail.

  1. 01
    01

    Pas de raccourcis

    Chaque combat se gagne au camp d'avant. Pas de routine bâclée, pas de récup' sautée. Le travail invisible est ce qui rend le travail visible spectaculaire.

  2. 02
    02

    Pas d'excuses

    Un blessé. Un défaite. Un mauvais round. Les explications n'effacent pas le résultat. La seule question qui compte : qu'est-ce que je fais demain.

  3. 03
    03

    Pas de filtre

    Les vlogs montrent tout. Les KO ET les doutes. Les victoires ET les nuits sans sommeil. La transparence n'est pas un risque : c'est ce qui construit la vraie confiance.

  4. 04
    04

    Mentalité d'entrepreneur

    Un athlète, c'est aussi une entreprise. Sponsors, médias, fans, équipe : ça se gère comme un projet. Avec rigueur, vision et discipline.

  5. 05
    05

    Le talent ne suffit pas

    Personne ne devient champion par accident. Le talent met sur la grille. Le travail décide de la place sur le podium.

Le travail parle plus fort que le talent.

C'est tout.
